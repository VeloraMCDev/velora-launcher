# Panel web

Svelte admin/player/landing frontend using shared frontend and SDK packages.

## Local checks

```sh
npm ci --no-audit --no-fund
npm run check
npm run check:runes
npm run build
```

Run commands from this directory. dist is a generated static bundle; API/authenticated operations need a compatible backend. Review access policy before independently hosting it.

See the root README for ownership, deployment and publication status.
