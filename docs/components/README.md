# Component contracts and attribution

These references describe reusable Authentication and Panel APIs and preserve
source attribution through exact provenance records. Package READMEs and the
root documentation describe current builds and deployment.

- [Authentication service](authentication/SERVICE.md), [configuration](authentication/CONFIGURATION.md) and [schema](authentication/SCHEMA.md)
- [Panel gateway](panel/GATEWAY.md), [distribution](panel/DISTRIBUTION.md) and [instances](panel/INSTANCES.md)

Historical source URLs and hashes in provenance JSON identify original source;
they are not required private build dependencies. Superseded owner-repository
introductions and migration tracker links have been removed.
